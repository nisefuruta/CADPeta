この文書は、CadPeta が AutoCAD および互換CADへ登録するコマンド `PETA` の、プロンプトとオプションを一つずつ示す。使い方の流れは 04_利用者向け文書.md、能力の一覧は 05_機能ガイド.md が扱う。プロンプト文言はプラグイン本体（`RangePrompt`）が出す文字列に一致する。

表示の言語は、ホスト CAD の言語に合わせて日本語と英語で切り替わる（それ以外の言語では英語になる）。本書ではプロンプトを日本語表示で示す。コマンド名、オプションのキーワード（All / Object などのグローバル名と A / O などの短縮名）、確認への応答（Y / Yes）は言語に依らず共通で、スクリプトや自動化は言語設定に影響されない。

## PETA[ペタ]（コマンド）

図面を Word / Excel / PowerPoint へ貼り付けるためのベクタ図（拡張メタファイル＝EMF）を作り、クリップボードへ登録します。範囲（全体・窓）をPDF印刷経由で処理し、ファイル出力オンまたは診断時は EMF・SVG・PDF を保存します。

出力する範囲は、[Enter]（全体）か窓の2点指定で必ず確定します。コマンドを起動したときに選択済みのオブジェクトがあると、その選択が「オブジェクト(O)」の絞り込みの初期値になります（範囲のプロンプトは省略されません）。

システム変数 PLOTTRANSPARENCYOVERRIDE は、プロット経由で透過を出力に反映するかを決めます。1 はページ設定の「透過性を印刷」に従い（既定）、2 は常に反映、0 は常に無視します。

次のプロンプトが表示されます。

**最初のコーナーを指定 または [全体(A)/オブジェクト(O)/余白(M)/レイヤ(L)/文字輪郭(T)/ファイル出力(F)/EMF背景(B)] <全体(A)>：** 窓の一方のコーナーを指定するか、オプションを入力します。[Enter]を押すと全体を出力します。

### [全体(A)]

レイアウトまたはモデル空間の全体を、ページ設定（用紙、尺度、プロットスタイル）どおりに変換します。[Enter]の既定と同じです。

レイアウトでは、ページ設定の尺度のまま（通常 1:1 なので用紙の実寸のまま）出力します。モデル空間では、図形範囲の全体を用紙に収めて（用紙合わせ、中央配置で）出力します。用紙合わせのため、モデル空間の貼り付けサイズは用紙寸法が基準になり、図面の縮尺どおりにはなりません。

ページ設定の用紙を PDF ドライバで利用できない場合は、ISO A4 縦（210×297mm）へ一時的に切り替え、図形範囲を用紙に収めて中央配置します。
図面のページ設定は変更しません。
既定用紙は、CAD の起動前に環境変数 `CADPETA_FALLBACK_PAPER_MM` を `幅mm,高さmm` の形式で設定すると変更できます。

### 2 点指定（窓）

最初のコーナーともう一方のコーナーで囲む範囲だけを切り出します。次のプロンプトが表示されます。

**もう一方のコーナーを指定：** 窓のもう一方のコーナーを指定します。

レイアウトでは、窓を用紙上のミリで指定し、ページ設定の尺度のまま切り出します（100×70mm の窓は 100×70mm の図として貼り付きます）。モデル空間では、窓の範囲を用紙に収めて変換します。ビューポートの中（モデル空間）で `PETA` を実行した場合は、窓を指定する間だけペーパー空間へ切り替わります。

窓の幅または高さが 0 のとき（同一点を二度指定したときなど）は「窓の幅または高さが 0 のため指定し直すこと」と表示し、指定し直しを求めます。切り出しの縁の精度は 0.2mm 程度です。縁ぎりぎりの線の切れや余りが許容できない場合は、余白(M)を付けます。

### [オブジェクト(O)]

範囲の中で出力するオブジェクトを、選択したものだけに絞ります。
オプションを入力するとオブジェクト選択を求め、選択を終えると範囲のプロンプトへ戻ります。範囲（[Enter]の全体か窓の2点指定）は絞り込みなしのときと同じ意味で効き、貼り付けサイズも同じ規則（レイアウト＝ページ設定の尺度、モデル空間＝用紙合わせ）で決まります。
何も選ばずに[Enter]を押した場合は絞り込みなしに戻ります（起動時の選択も外れます）。

通常の絞り込みでは、現在空間直属の選択オブジェクトだけを側DBへ一時複製し、元のページ設定を引き継いでPDF印刷します。
ペーパー空間のOnである通常ビューポートを含む場合は元レイアウトを一時隔離して印刷し、そのビューポートの尺度、視点、クリップ、VPフリーズ、画層overrideを保持します。
オブジェクト(O)はビューポート内の非表示レイヤや非表示モデル図形を表示へ戻しません。
ペーパー空間の制御ビューポート、オフのビューポート、現在空間以外の図形は対象外です。
元図面を変更せず、CTB/STB、色、線幅を反映します。
非印刷レイヤから一時退避するのは、直接選択した非ビューポート図形だけです。
Xref等の未対応図形が混在する場合は既定で中止し、確認へ同意した場合のみ部分出力を行います。

### [余白(M)]

切り出し範囲の外側へ付ける余白を指定します。次のプロンプトが表示されます。

**クロップの余白をmmで指定：** 余白を mm で入力します。既定は 0 で、0 も指定できます。[Enter]は現在値のままにします。

### [レイヤ(L)]

SVG をレイヤごとのグループにするかを切り替えます（既定オフ）。オンにすると「レイヤ別グループ化: オン（描画順が変わり見た目が崩れ得る。SVG のグループ構造と EMF の描画順の両方に反映）」と表示します。

SVG 編集ソフトでレイヤ単位に扱う用途に向きます。描画の順番が変わるため、重なりの見た目が崩れることがあり、その影響は EMF の描画順にも及びます。

レイヤ情報は発行 PDF のレイヤ（OCG）から取得します。
PDF ドライバの設定によりレイヤ情報が埋め込まれない場合は、警告を表示し、レイヤ別グループ化を行わずに出力を続けます。

### [文字輪郭(T)]

TrueType を含むすべての文字を輪郭の図形にするかを切り替えます（既定オフ、フォント保持）。オンにすると「文字アウトライン化: オン（すべての文字を輪郭の図形にする。環境非依存の見た目になるが文字編集はできない）」と表示します。

フォントが入っていない PC でも見た目が変わりません。オンにすると文字編集はできなくなります。

### [ファイル出力(F)]

図面フォルダへのファイル出力のオンとオフを切り替えます（既定オン）。切り替えると現在の状態を「ファイル出力: オン」または「ファイル出力: オフ」と表示します。

オフにすると、貼り付け用の一時 EMF だけを内部で作り、クリップボード登録の後に削除します。この場合も貼り付け自体は行えます。

### [EMF背景(B)]

EMF で半透明の要素を不透明化するときの下地色を指定します。次のプロンプトが表示されます。

**EMFの透過合成下地色を #RRGGBB で指定 <#FFFFFF>：** 下地色を #RRGGBB 形式で入力します。既定は #FFFFFF（白）です。[Enter]は現在値のままにします。色付きの貼り付け先へ置く場合は、その色を指定します。

#RRGGBB 形式でない入力には「EMF背景色は #RRGGBB 形式で指定すること」と表示し、下地色は変えません。この指定は EMF の不透明化だけに作用し、SVG、PDF、PNG のアルファには影響しません。

## 出力ファイルと退避先

`PETA` が図面フォルダへ出力するファイルは次のとおりです。

| ファイル | 内容 |
|---|---|
| `<図面名>_<レイアウト名>_<年月日_時分秒>.emf` | Office 貼り付け用のベクタ図（Ctrl+V で貼られるものと同一） |
| `〃.svg` | ブラウザで開ける形式。透過を保持する。長期保存・再利用向け |
| `〃.pdf` | 変換の元になった印刷イメージ（絞り込み時も保存） |

図面フォルダへ書き込めない場合と、図面が未保存の場合は、出力先を尋ねます。[Enter]だけで応じると `%TEMP%\CadPeta` へ出力します。

## 関連コマンド

貼り付けとコマンドライン版は次を使います。

- Ctrl+V（貼り付け）　クリップボードに登録された EMF を、貼り付け先へ貼ります。
- ファイル挿入　クリップボード登録に失敗した場合（他アプリが使用中など）は、出力済みの `.emf` を Office へファイル挿入します。
- `cadpeta.exe`（コマンドライン版）　CAD が手元にない場合や、受け取ったベクタ PDF から貼る場合に使います。オプションは 04_利用者向け文書.md の第10章にあります。
- `cadpeta-gui.exe`（GUI 版）　受け取ったベクタ PDF を画面へドロップし、色・背景・クロップ・文字・レイヤを調整して、Office へ貼るか EMF / SVG / PDF / PNG へ保存します。CAD を必要としません（.NET 10 Desktop Runtime x64 が必要）。段階診断のダンプは `cadpeta.exe --diag` を使います。

## PETADATA（構造SVG書き出し）

先選択またはコマンド後に選択したオブジェクトをCAD DBから直接取得し、編集用SVGだけを保存する。
CTB/STBを反映する貼付コマンドではなく、文字・レイヤ・元の色を保ってInkscape等で再編集するためのコマンドである。
尺度、余白、レイヤ、SHX代替、文字輪郭、グラデーションDPIを指定できる。EMF、PDF、クリップボードは生成しない。

対象は現在の空間（モデル空間、またはカレントレイアウトのペーパー空間）直属のオブジェクトに限る。
他の空間に属するオブジェクトが選択に含まれる場合は、件数を表示して除外し、除外の内訳を診断へ記録する。
すべて対象外の場合は書き出しを中止する。

## 開発者向け

変換の不具合を切り分けるためのデバッグ用コマンドを別に用意している。通常の利用では使わない。仕様は 03_技術解説.md 第9章にある。

- `PETADIAG`　PETA（印刷経路）の変換各段を SVG へダンプし、診断ログ（diag.json）を書き出す。
- `PETADATADIAG`　PETADATA（構造SVG書き出し）で同じ段階診断を行う。
