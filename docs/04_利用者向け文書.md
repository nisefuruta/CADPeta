## 1. CadPeta は何をするか

CadPeta は、AutoCAD の図面を Word / Excel / PowerPoint へ「拡大しても劣化しない図」として貼り付けるフリーソフトウェアです。
コマンド一つで、印刷(プロット)と同じ仕上がり（プロットスタイル(CTB/STB)による色・線の太さを反映した見た目）の図がコピーされた状態になり、Office 側で Ctrl+V するだけで用紙どおりの実寸で貼り付きます。

- 貼り付けた図はベクタ形式(拡張メタファイル=EMF)で、拡大しても粗くなりません
- Excel / PowerPoint では図形に分解して、線・塗り・文字を個別に編集できます(第6章)
- EMF のファイルも出力します。`PETAOPT` で設定すれば、SVG(ブラウザで開ける長期保存向けの形式)、PDF(変換の元になった印刷イメージ)、PNG(画像)も出力します
- CADの文字・レイヤ・元の色を保った編集用SVGが必要な場合は、貼付用の `PETA` ではなく `PETADATA` を使います

レイアウト(またはモデル空間)の全体を丸ごと貼るほか、2点指定の窓で任意範囲だけを切り出して貼れます(第4章)。
さらに、現在空間（モデル空間または現在のレイアウト）で選択したオブジェクトだけを、指定した実寸尺度で貼ることもできます(第4章)。
AutoCAD が手元になくても、受け取ったベクタ PDF の図を同じ品質で貼れます(コマンドライン版は第10章、GUI 版は第12章)。

## 2. 使い始める

必要な環境:

- AutoCAD 2024 / 2026 / 2027(動作確認済み)。2025 は 2026 と同じ仕組み(.NET 8)で動作します
- ARES Standard 2020／2023／2024／2027、IJCAD 2026 PRO、BricsCAD V26に対応します。ARES 2020／2023 は .NET Framework 4.8 版で動きます。この .NET Framework は Windows 10／11 に標準で入っています。IJCAD と BricsCAD は、この版(1.1.0)を実機で確かめていません
- プロッタ構成「AutoCAD PDF (High Quality Print).pc3」(AutoCAD 標準搭載)。CadPeta は内部でこのドライバを使います
- Word / Excel / PowerPoint(Windows デスクトップ版)

インストールの手順(AutoCAD):

1. `CADPeta-AutoCAD-x.y.z.zip` を展開し、`install.bat` を実行します(管理者権限は不要)。`CADPeta.bundle` が `%APPDATA%\Autodesk\ApplicationPlugins\` へコピーされます
2. AutoCAD を起動し、コマンド `PETA` が使えれば準備完了です。AutoCAD の版に合った DLL が自動で読み込まれるので、`NETLOAD` は要りません
3. 読み込まれない場合(SECURELOAD の設定による)の対処は、同梱の `README-install.txt` にあります

アンインストールは同梱の `uninstall.bat` で行います。

互換CAD(ARES・IJCAD・BricsCAD)では、`CADPeta-CompatCAD-x.y.z.zip` を展開し、`install.bat` を実行して製品を選ぶと、自動で読み込まれるように登録されます。
登録しないで CAD の中から手動で読み込む方法は、同梱の `README-compat.txt` にあります。
PDFデバイスは ARES=`PDF`、IJCAD=`DWG To PDF.pc3`、BricsCAD=`Print As PDF.pc3` を内部で使用します。

## 3. 基本の使い方: PETA → Ctrl+V

1. 貼りたいレイアウトタブを開きます
2. `PETA` を実行します。「最初のコーナーを指定 または [全体(A)/オブジェクト(O)/余白(M)/レイヤ(L)/文字輪郭(T)/EMF背景(B)] <全体(A)>:」と聞かれるので、全体を貼るなら Enter、範囲を切り出すなら2点を指定します。出力対象を選択オブジェクトだけに絞るなら `O` を入力します(第4章)
3. Word / Excel / PowerPoint で Ctrl+V します

`PETA` は次を一度に行います。

- 現在のレイアウトを、ページ設定(用紙・尺度・プロットスタイル)どおりに変換します。プリンタだけは上記の PDF ドライバへ差し替えます
- `PETAOPT` で設定した形式のファイルを、設定した出力先へ出力します。既定は EMF だけを、図面のフォルダの下の `CADPeta` フォルダへ、図面名・タブ名・実行日時の名前で出力します。形式・出力先・ファイル名の形・PNG の解像度は `PETAOPT`(ダイアログ)か `-PETAOPT`(コマンド ライン)で変更します(06_コマンドリファレンス.md)

ページ設定の用紙を PDF ドライバで利用できない場合は、ISO A4 縦（210×297mm）を一時的に使い、図形範囲を用紙に収めて中央配置します。
この一時設定は `PETA` の出力だけに適用され、図面のページ設定には保存されません。
既定用紙を変更する場合は、CAD を起動する前に環境変数 `CADPETA_FALLBACK_PAPER_MM` を `幅mm,高さmm` の形式で設定します（A3 縦は `297,420`）。

| 出力ファイル | 内容 |
|---|---|
| `<図面名>_<タブ名>_<年月日_時分秒>.emf` | Office 貼り付け用のベクタ図(Ctrl+V で貼られるものと同一)。既定で出力します |
| `〃.svg` | ブラウザで開ける形式。透過を保持します。長期保存・再利用向け |
| `〃.pdf` | 変換の元になった印刷イメージ |
| `〃.png` | 画像(既定 300dpi) |

- 図をコピー済みの状態にします。AutoCAD を閉じた後でも Ctrl+V で貼り付けられます
- ファイル名の形に `{comment}` を入れると、`PETA` のたびにコメントを入力するダイアログが開き、入力したコメントをファイル名に入れます。コメントを入力している間に、図の変換が進みます
- 同じ名前のファイルがあるときは、名前の後に (1)、(2) のような番号を付けて出力します
- 出力先へ書き込めない場合と未保存図面の場合は、出力先を尋ねます(Enter だけなら `%TEMP%\CadPeta` へ出力します)
- AutoCAD と ARES(2020 を除く)では、リボンの「アドイン」タブの CADPeta のパネルから `PETA` と `PETAOPT` を実行できます

貼り付け直後のサイズは用紙の実寸になります(例: A3 レイアウトなら約 420×297mm。実測誤差は 0.1mm 程度)。レイアウトの印刷尺度を変えれば、その尺度どおりの大きさで貼り付きます。
ページ設定の用紙を利用できず A4 縦へ切り替えた場合は、貼り付け直後のサイズも約 210×297mm になります。

留意: ビューポートの枠線は、枠線のレイヤが印刷対象のままだと図に含まれます。枠線を出したくない場合は、枠線用レイヤを印刷しない設定にしてください。

## 4. 範囲を切り出して貼る(窓指定)・モデル空間の図面を貼る

`PETA` の最初のプロンプトで2点を指定すると、その窓の範囲だけを切り出して貼れます。

- **モデル空間**: 窓の範囲を、ページ設定の用紙に収めて(用紙合わせ・中央配置で)変換します。Enter(全体)の場合は図形範囲の全体を同じく用紙合わせで変換します。用紙合わせのため、貼り付けサイズは用紙寸法が基準になり、図面の縮尺どおりにはなりません。縮尺どおりの実寸で貼りたい図は、レイアウトにビューポートを置いて尺度を設定し、そのレイアウトで窓指定してください
- **レイアウト**: 窓は用紙上のミリで指定し、ページ設定の尺度のまま(通常 1:1 なので用紙上の実寸のまま)切り出されます。例えば 100×70mm の窓は 100×70mm の図として貼り付きます。ビューポートの中(モデル空間)に入った状態で `PETA` を実行した場合は、窓指定の間だけ自動でペーパー空間へ切り替わります
- **余白**: プロンプトで `M` を入力すると、切り出し範囲の外側へ付ける余白(mm)を指定できます(既定 0)
- 切り出し範囲の縁の精度は 0.2mm 程度です。縁ぎりぎりの線の切れ・余りが許容できない場合は余白を付けてください
- **レイヤ**: `L` を入力すると、SVG がレイヤごとのグループになります(SVG 編集ソフトでレイヤ単位に扱う用途向け。描画の順番が変わるため重なりの見た目が崩れることがあり、EMF の描画順にも及びます。既定はオフ)
- **文字輪郭**: `T` を入力すると、TrueType を含む**すべての文字**が輪郭の図形として出力されます(フォントが入っていない PC でも見た目が変わりません。文字編集はできなくなります。既定はオフ=フォント保持)

### 出力対象を選択オブジェクトだけに絞る(オブジェクト選択)

範囲(全体・窓)とは別に、その範囲の中で出力するオブジェクトを選択したものだけに絞れます。

1. オブジェクトを選択してから `PETA` を実行します。または `PETA` → `O` を入力してからオブジェクトを選択します(何も選ばず Enter すると絞り込みなしに戻ります)
2. 続けて範囲を指定します。Enter(全体)か、2点指定の窓かは、絞り込みなしのときと同じ意味で効きます

貼り付けサイズも絞り込みなしのときと同じ規則で決まります。レイアウトはページ設定の尺度のまま(通常 1:1 なので用紙上の実寸)、モデル空間は用紙合わせになります。

知っておくこと:

- 通常の選択図形は側DB（サイドデータベース。画面に開かない一時的な図面データベース）へ複製してPDF印刷するため、**CTB/STB、色、線幅が反映されます**。ビューポート選択は元図面の未確定トランザクション内で非選択のペーパー空間図形だけを隠して印刷します。どちらも元図面に変更を残しません。PDF を出力する設定か診断時は、内部生成PDFも保存します
- Defpoints等の非印刷レイヤにある非ビューポート図形を明示的に選んだ場合は、一時的な退避レイヤへその図形だけを移して出力します。通常ビューポートと同時に選んだ場合も、元レイヤや図面には変更を残しません
- 対象は現在の空間(モデル空間、またはカレントレイアウトのペーパー空間)直属のオブジェクトに限ります。ペーパー空間のOnである通常ビューポートを選択すると、そのビューポートの尺度、視点、クリップ、VPフリーズ、画層overrideを通常のレイアウト印刷どおり反映します。`O`はビューポート内の非表示レイヤや非表示モデル図形を表示へ戻しません
- Xref、ペーパー空間の制御ビューポート、オフのビューポート、現在空間以外の図形など未対応の選択がある場合は既定で中止し、確認に同意した場合だけ対応図形を部分出力します
- 文字(マルチテキスト)の背景マスクは背景ごと再現されます。背景に「図面の背景色を使用」を指定した文字(寸法値の背景によく使われる)は**白い塗りとして出力され、黒く塗りつぶされることはありません**
- SHX文字はCADの印刷結果どおり輪郭として出ます。文字として再編集したい場合は `PETADATA` で構造SVGを書き出してください

### CAD構造を保ったSVGを書き出す（PETADATA）

`PETADATA` は選択オブジェクトをCADデータベースから直接読み、外部編集用SVGを保存します。
先選択してから実行するか、コマンド後にオブジェクトを選びます。
文字、レイヤ、元の色を保持し、貼付用EMF、内部PDF、クリップボードは生成しません。
CTB/STBは反映されません。
印刷と同じ見た目をOfficeへ貼る通常用途には `PETA`、InkscapeやIllustrator等でCAD構造を再編集する用途には `PETADATA` を使います。
尺度、余白、レイヤ、SHX代替、文字輪郭、グラデーションDPIを指定できます。

## 5. 貼り付け先ごとの注意

### Excel / PowerPoint

- Ctrl+V でそのまま貼り付きます。サイズは実寸(誤差 0.1mm 程度)です
- PowerPoint では、スライドからはみ出す大きさの図は、スライドに収まるよう縦横比を保って自動縮小されます
- 図形への分解(第6章)は、この2アプリで行います

### Word(実寸の図として使う)

- Word でそのまま Ctrl+V すると、既定では描画キャンバス（複数の図形をまとめて置く Word の枠）の中に入ることがあります。実寸の図として貼るには、「形式を選択して貼り付け」→「図 (拡張メタファイル)」を選んでください
- **描画キャンバスの中に入れないでください。** キャンバス内の図はキャンバスの大きさに合わせて縮小され、後からキャンバスを伸縮すると図も一緒に伸縮します。実寸を保つ用途に向きません
- 本文の幅より大きい図は、本文幅まで自動縮小されます(例: A4 の既定設定では幅 150mm)。実寸が必要な場合は、貼り付けた後に図のサイズを数値で指定し直してください。自動縮小でも縦横比は保たれています
- 図形への分解は Word では行いません(動作が不安定なため)。分解して編集したい図は Excel / PowerPoint に貼ってください

## 6. 図形に分解して編集する(Excel / PowerPoint)

貼り付けた図を右クリック→「グループ化」→「グループ解除」すると、図が個々の図形に変換され、線・塗り・文字を個別に編集できます。TrueType フォントの文字は文字のまま取り出され、フォントを保ったまま書き換えられます。

知っておくこと(Office 側の変換仕様):

- **分解した瞬間に、線の太さが画面の画素単位(0.75pt 刻み)へ丸められます。** 太さ 0.13〜0.35mm の線はすべて 0.75pt になり、0.05mm 以下の線は 0pt(最も細い線)になります。細い線を何段階か使い分けた図面でも、分解後は同じ太さに見えます
- 分解せず画像のまま使う限り、線の太さは表示・印刷とも忠実に保たれます
- **Excel の分解では、日本語の一部の文字が「・」などに化けることがあります**(Shift-JIS で2バイト目が特殊文字と重なる文字。例: ソ 能 表 施 図)。また、分解時に文字列の先頭へ「・」が挿入されることがあります。いずれも Excel 側の変換の不具合で、Windows 標準機能で作った図でも同様に化けることを確認しています。貼り付けたまま(画像のまま)なら化けません。PowerPoint の分解では起きません
- **図形の数が 1 万を超える図は、Excel と PowerPoint のどちらでもグループ解除(図形への変換)が失敗します。** 実測では、変換後の図形数 10,000 個までは成功し、10,001 個で失敗しました。この閾値は Excel と PowerPoint で同じです。ファイルの大きさや線の込み具合ではなく、図形の個数だけで決まります(同じ大きさのファイルでも図形数が 1 万以下なら成功します)。失敗しても貼り付けそのものと実寸表示は正常で、影響は図形へ分解できないことだけです

どうすればよいか:

- 線の太さの仕上がりが大事な図は、分解せず画像のまま貼ってください
- 分解して編集した図で太さの使い分けが必要な線は、Office 側で太さを指定し直してください
- 文字の編集が要る図は PowerPoint で分解してください。分解した図形は PowerPoint から Excel へコピーしても文字が保たれます(確認済み)
- 図形数が 1 万を超える図面(詳細の多い施工図等)は、分解せず画像のまま使ってください。分解編集が必要な場合は、`PETA` の範囲指定(2点窓)で編集したい範囲だけを切り出し、図形数を 1 万以下に抑えて貼ってください

## 7. 透過(透過性)を含む図面

オブジェクトやレイヤに透過性を設定している図面では、透過を仕上がりへ残すかどうかが AutoCAD の印刷設定で決まります。`PETA` はその設定に従います。

- 対象レイアウト(またはモデルタブ)のページ設定で「透過性を印刷」をオンにすると、`PETA` の出力にも透過が反映されます。オフのまま実行すると、透過は消えてすべて不透明で出力されます
- システム変数 `PLOTTRANSPARENCYOVERRIDE` でまとめて制御することもできます: 1=ページ設定に従う(既定)、2=常に透過を印刷、0=常に無視
- 透過を反映した場合の見え方は、出力形式で異なります
  - Ctrl+V で貼る図(EMF)は、白い紙の上で見た色に固定されます(半透明のまま下が透ける表現を持たないため、白と混ぜた不透明色になります)。濃い色の背景へ置くと、白地で見た色のまま表示されます。半透明の下に重なっていた線や図形も、不透明化した色に覆われて透けません
  - SVG ファイルは透過をそのまま保持します
- 透過の不透明化が起きた実行では、`PETA` が結果表示に続けて「透過図形検出。透過表現はSVGファイルを利用のこと」の注記をコマンドラインへ表示します
- 半透明の塗りつぶし(SOLID ハッチ×透過)は、AutoCAD の印刷段階で画像に変換されます(第8章)

## 8. 変換の制約と対処

方式上どうしても起きる変化を「何が起きるか → どうすればよいか」で挙げます。

| 何が起きるか | どうすればよいか |
|---|---|
| SHX フォントの文字は線の集まりになり、文字としては編集できません | TrueTypeフォントを使うか、構造編集が必要なら `PETADATA` のSVGを使います |
| 斜体(傾斜角)を付けた TrueType 文字は直立で出力されます(AutoCAD の印刷出力自体が傾斜を持たないため)。幅係数は保持されます | 傾斜の再現が必要な注記には傾斜角を使いません |
| スプラインや線種付きの曲線は細かい折れ線になります | 見た目は保たれます。分解した後に曲線として編集し直す用途には向きません |
| 半透明の SOLID ハッチは画像になります(大きく拡大すると粗く見え、分解しても図形に戻りません) | 分解編集や高倍率の拡大が要る図では、ハッチの透過を外します(ハッチの境界や線は透過のままでも図形として保たれます) |
| 図面へ貼り込んだ OLE オブジェクト(Excel の表など)や画像は、画像のまま含まれ、ファイルが大きくなることがあります | 表は図面へ貼り込まず Office 側で組むなど、元データの側で減らせます |
| 文字(マルチテキスト)の背景の「図面の背景色を使用」は、白い塗りとして出力されます(貼り付け先=白い紙面を前提とするため) | 濃い色の背景へ置く資料では、背景マスクに明示的な色を指定します |

なお、Windows の表示スケール設定(125%・150% 等)は貼り付け寸法に影響しません(100/125/150% × 3アプリで同一寸法になることを確認済み)。

## 9. うまくいかないとき

- `PETA` はエラーの原因と対処をコマンドラインへ表示します。まずその表示を読んでください
- クリップボードへの登録に失敗した場合(他のアプリが使用中など)も、ファイルは出力済みです。表示されたアプリの操作を終えてから `PETA` を再実行するか、出力済みの `.emf` を Office へファイル挿入してください
- 不具合を報告するときは、コマンドラインの表示全文と、出力ファイル一式（`PETAOPT` で PDF・SVG・EMF を出力する設定にして出力したもの）を添えてください。切り分けに必要なら開発側が同じ操作を再現して調べます

## 10. 受け取った PDF の図を貼る(コマンドライン版)

AutoCAD が手元にない場合や、他社から図面を PDF でだけ受け取った場合は、コマンドライン版 `cadpeta.exe` で同じ品質の貼り付けができます。対象は CAD からプロットされたベクタ PDF です(スキャンした画像だけの PDF は、画像のまま貼られます)。

基本の使い方(コマンドプロンプトまたは PowerShell で):

```
cadpeta.exe 受領図面.pdf
```

これだけで図がコピーされた状態になり、Office で Ctrl+V すると PDF の用紙実寸で貼り付きます。貼り付け用の EMF ファイルは一時フォルダ(`%TEMP%\cadpeta`)にも残り、パスが表示されます。クリップボードへの登録に失敗した場合も、この EMF を Office へファイル挿入すれば同じ結果になります。

PDF が複数ページのときは、`--pages` で変換するページを選びます。指定しなければ 1 ページ目を変換します。どのページを変換したかは、コマンドラインに「ページ: 1/5」のように表示されます。

| コマンド | 動作 |
|---|---|
| `cadpeta.exe 図面.pdf --pages 3` | 3 ページ目を変換し、クリップボードへ登録します |
| `cadpeta.exe 図面.pdf 図面.svg --pages 1-3,5` | 1～3 ページと 5 ページを変換します。ファイル名にページの番号を付けます(`図面-p1.svg` など)。クリップボードへ登録できるのは 1 ページだけなので、2 ページ以上は出力の SVG（ここでは `図面.svg`）を指定し、`--clipboard` を付けないでください |

色を変えて貼る(カラーで受け取った図面をモノクロ資料へ載せる、など):

| コマンド | 動作 |
|---|---|
| `cadpeta.exe 図面.pdf --mono` | モノクロ化(紙面の白はそのまま、他の色は黒) |
| `cadpeta.exe 図面.pdf --gray` | グレースケール化(明るさを保った灰色) |
| `cadpeta.exe 図面.pdf --replace-color #FF0000 #000000` | 特定の色だけを置換(この例は赤→黒。複数回指定できます) |
| `cadpeta.exe 図面.pdf --replace-color #FF0000 #000000 --tolerance 8` | 近い色もまとめて置換(R・G・B のそれぞれの差が 8 以内の色。`--tolerance` は直前の `--replace-color` に付きます。0～255、既定は 0 で同じ色だけ。複数の置換に一致する色は、先に指定した置換を使います) |
| `cadpeta.exe 図面.pdf --text-outline` | すべての文字を輪郭の図形にする(フォントが入っていない PC でも見た目が変わりません。文字編集はできなくなります) |

ファイルとして残したい場合は出力名を指定します(この形はクリップボードへ登録しません。登録も併用するなら `--clipboard` を付けます):

```
cadpeta.exe 図面.pdf 図面.svg --emf 図面.emf
```

PDF・PNG のファイルも出力できます(Office 貼り付けの主役は引き続き EMF/SVG で、PDF は単票の受け渡し、PNG は見た目の確認用です):

| コマンド | 動作 |
|---|---|
| `cadpeta.exe 図面.pdf 図面.svg --pdf 出力.pdf` | PDF を出力する(用紙実寸を保持。文字は輪郭の図形として埋め込むため、出力後の PDF では文字の検索・編集はできません) |
| `cadpeta.exe 図面.pdf 図面.svg --png 出力.png` | PNG(画像)を出力する(既定 300dpi) |
| `cadpeta.exe 図面.pdf 図面.svg --png 出力.png --png-dpi 150` | PNG の解像度を指定する(24～600dpi) |

色変換やクロップと組み合わせられます(例: `--mono --pdf 出力.pdf` でモノクロ化した PDF を渡す)。

処理の内容(何を何件変換したか)はコマンドラインに表示されます。うまくいかないときの考え方は第9章と同じです。

## 11. グラデーションと貼り付け背景

`PETADATA` の尺度のプロンプトでは、`G`でグラデーション画像化の解像度をdpi指定できます
(既定150dpi)。LINEARを含む全9形状に対応します。グラデーションは見た目を保つ画像になるため、
Excel / PowerPointで図形へ変換しても、その部分はベクタ図形へ分解されません。

`PETA` の `B`では、EMFの半透明要素を不透明化するときの背景色を`#RRGGBB`で指定できます(既定白)。
色付きのスライドへ置く場合は貼付先と同じ色を指定してください。CLIでは次のように指定します。

`cadpeta.exe 図面.pdf 図面.svg --emf 出力.emf --emf-bg "#102030"`

`--emf-bg`はEMF出力またはクリップボード登録と組み合わせます。SVG/PDF/PNGのアルファには影響しません。

## 12. 受け取った PDF の図を貼る(GUI 版)

GUI 版 `cadpeta-gui.exe` は CAD を必要としません(.NET 10 Desktop Runtime x64 が必要です)。

1. `cadpeta-gui.exe` を起動し、受け取った PDF を画面へドロップするか、「参照…」で選びます。PDF を `cadpeta-gui.exe` へドロップして起動することもできます
2. 複数ページの PDF は、上の「ページ」の欄と ‹ › のボタン(または PageUp・PageDown キー)で変換するページを選びます
3. 左の欄で色、背景、範囲の切り出し、文字のアウトライン化、レイヤ、色置換を設定し、右のプレビューで確かめます。設定を変えると、プレビューは自動で更新されます
4. 「クリップボードにコピー」を押して Word・Excel・PowerPoint などに貼り付けるか、「保存…」で保存します。保存は「保存する形式」でチェックした形式で行います。形式が 1 つならファイル名を、2 つ以上なら基本のファイル名を指定します(形式ごとの拡張子が付きます)。複数ページの PDF では、既定のファイル名にページの番号が付きます
5. クリップボードへのコピーに失敗した場合は、案内された EMF を Office の「挿入 > 図」から選びます

画面の配色は、Windows のアプリの配色(暗い・明るい)に合わせます。下のステータス バーに、ページ、用紙の大きさ、切り出す範囲の大きさ、背景を除去した件数を表示します。
大きな PDF の処理の途中で画面を閉じたり設定を変えたりすると、処理の区切りまで進んでから止まるので、少し待つことがあります。変換の段階ごとの診断のダンプが必要なときは、コマンドライン版の `--diag` を使ってください。

範囲の切り出しは、「範囲を切り出す」をオンにして数値(mm)を入力するか、「ドラッグで指定」を押してページ全体のプレビューの上をドラッグして指定します。
ドラッグで指定すると、指定した枠と出力の範囲を一致させるため、余白は 0 になります。Esc キーか同じボタンで、ドラッグでの指定をやめられます。

色置換は、「追加」で行を足し、変換前と変換後の色(#RRGGBB)と許容差(±)を入力します。色見本を押すと、色の選択の画面が開きます。
許容差は R・G・B のそれぞれの差の上限で、0 は同じ色だけ、8 なら差が 8 以内の近い色もまとめて置き換えます。複数の行に一致する色は、上の行で置き換えます。
行の下に、行ごとに一致した色の数と件数を表示するので、許容差が広すぎて別の色まで置き換えていないかを確かめられます。

使用色の一覧には、図面のすべての色を使用の多い順に表示します。色見本を押すと、選択中の行(行が無ければ新しい行)の「変換前」に入ります。
「スポイト」を押すと元の色のプレビューに切り替わり、線や塗りをクリックすると、その位置で一番上に描かれた図形の色がそのまま入ります。近い色が多い図面でも、別の色と取り違えません。
細い線は、少し外れた位置をクリックしても選べます。何も描かれていない位置と画像は選べません(画像は色置換の対象外です)。
