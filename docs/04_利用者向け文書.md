## 1. CadPeta は何をするか

CadPeta は、AutoCAD の図面を Word / Excel / PowerPoint へ「拡大しても劣化しない図」として貼り付けるフリーソフトウェアである。
コマンド一つで、印刷(プロット)と同じ仕上がり（プロットスタイル(CTB/STB)による色・線の太さを反映した見た目）の図がコピーされた状態になり、Office 側で Ctrl+V するだけで用紙どおりの実寸で貼り付く。

- 貼り付けた図はベクタ形式(拡張メタファイル=EMF)であり、拡大しても粗くならない
- Excel / PowerPoint では図形に分解して、線・塗り・文字を個別に編集できる(第6章)
- あわせて SVG(ブラウザで開ける長期保存向けの形式)と PDF(変換の元になった印刷イメージ)も出力する
- CADの文字・レイヤ・元の色を保った編集用SVGが必要な場合は、貼付用の `PETA` ではなく `PETADATA` を使う

レイアウト(またはモデル空間)の全体を丸ごと貼るほか、2点指定の窓で任意範囲だけを切り出して貼れる(第4章)。
さらに、現在空間（モデル空間または現在のレイアウト）で選択したオブジェクトだけを、指定した実寸尺度で貼ることもできる(第4章)。
AutoCAD が手元になくても、受け取ったベクタ PDF から同じ品質で貼れる(第10章)。

## 2. 使い始める

必要な環境:

- AutoCAD 2024 / 2026 / 2027(動作確認済み)。2025 は 2026 と同じ仕組み(.NET 8)で動作する
- ARES Standard 2020／2023／2024／2027、IJCAD 2026 PRO、BricsCAD V26に対応する。ARES 2020／2023 は .NET Framework 4.8 版で動く。この .NET Framework は Windows 10／11 に標準で入っている
- プロッタ構成「AutoCAD PDF (High Quality Print).pc3」(AutoCAD 標準搭載)。CadPeta は内部でこのドライバを使う
- Word / Excel / PowerPoint(Windows デスクトップ版)

読み込みの手順:

1. AutoCAD で `NETLOAD` を実行し、AutoCAD の版に合ったフォルダの `CadPeta.Plugin.Acad.dll` を選ぶ(2024以前=net48、2025・2026=net8.0-windows、2027=net10.0-windows)
2. セキュリティの確認が出たら「常にロード」を選ぶ
3. コマンド `PETA` が使えれば準備完了(NETLOAD は AutoCAD を起動し直すたびに必要)

互換CADでは製品別DLLを読み込む。ARESは `LoadDotNetApplication`、IJCAD 2026 PRO と BricsCAD V26 は `NETLOAD` を使う。
ARES は版でフォルダが分かれる。ARES Standard 2020=`ares\2020`、2023=`ares\2023`、2024=`ares\2024`(いずれも .NET Framework 4.8 版)、2027=`ares\2027`(.NET 8 版)から、使う版のフォルダの `CadPeta.Plugin.Ares.dll` を選ぶ。IJCAD と BricsCAD は `net8.0-windows` のフォルダを選ぶ。BricsCADではダッシュ付きの `-NETLOAD` / `_.-NETLOAD` は使わない。
PDFデバイスは ARES=`PDF`、IJCAD=`DWG To PDF.pc3`、BricsCAD=`Print As PDF.pc3` を内部で使用する。

## 3. 基本の使い方: PETA → Ctrl+V

1. 貼りたいレイアウトタブを開く
2. `PETA` を実行する。「最初のコーナーを指定 または [全体(A)/オブジェクト(O)/余白(M)/レイヤ(L)/文字輪郭(T)/ファイル出力(F)/EMF背景(B)] <全体(A)>:」と聞かれるので、全体を貼るなら Enter、範囲を切り出すなら2点を指定する。出力対象を選択オブジェクトだけに絞るなら `O` を入力する(第4章)
3. Word / Excel / PowerPoint で Ctrl+V する

PETA は次を一度に行う。

- 現在のレイアウトを、ページ設定(用紙・尺度・プロットスタイル)どおりに変換する。プリンタだけは上記の PDF ドライバへ差し替える
- 既定では図面と同じフォルダへ、実行時刻付きの名前でファイルを出力する。`ファイル出力(F)` でオフにすると、Office貼り付け用の一時EMFだけを内部生成し、登録後に削除する

ページ設定の用紙を PDF ドライバで利用できない場合は、ISO A4 縦（210×297mm）を一時的に使い、図形範囲を用紙に収めて中央配置する。
この一時設定は PETA の出力だけに適用され、図面のページ設定には保存されない。
既定用紙を変更する場合は、CAD を起動する前に環境変数 `CADPETA_FALLBACK_PAPER_MM` を `幅mm,高さmm` の形式で設定する（A3 縦は `297,420`）。

| 出力ファイル | 内容 |
|---|---|
| `<図面名>_<レイアウト名>_<年月日_時分秒>.emf` | Office 貼り付け用のベクタ図(Ctrl+V で貼られるものと同一) |
| `〃.svg` | ブラウザで開ける形式。透過を保持する。長期保存・再利用向け |
| `〃.pdf` | 変換の元になった印刷イメージ |

- 図をコピー済みの状態にする。AutoCAD を閉じた後でも Ctrl+V で貼り付けられる
- 図面フォルダへ書き込めない場合と未保存図面の場合は、出力先を尋ねる(Enter だけなら `%TEMP%\CadPeta` へ出力する)

貼り付け直後のサイズは用紙の実寸になる(例: A3 レイアウトなら約 420×297mm。実測誤差は 0.1mm 程度)。レイアウトの印刷尺度を変えれば、その尺度どおりの大きさで貼り付く。
ページ設定の用紙を利用できず A4 縦へ切り替えた場合は、貼り付け直後のサイズも約 210×297mm になる。

留意: ビューポートの枠線は、枠線のレイヤが印刷対象のままだと図に含まれる。枠線を出したくない場合は、枠線用レイヤを印刷しない設定にする。

## 4. 範囲を切り出して貼る(窓指定)・モデル空間の図面を貼る

`PETA` の最初のプロンプトで2点を指定すると、その窓の範囲だけを切り出して貼れる。

- **モデル空間**: 窓の範囲を、ページ設定の用紙に収めて(用紙合わせ・中央配置で)変換する。Enter(全体)の場合は図形範囲の全体を同じく用紙合わせで変換する。用紙合わせのため、貼り付けサイズは用紙寸法が基準になり、図面の縮尺どおりにはならない。縮尺どおりの実寸で貼りたい図は、レイアウトにビューポートを置いて尺度を設定し、そのレイアウトで窓指定する
- **レイアウト**: 窓は用紙上のミリで指定し、ページ設定の尺度のまま(通常 1:1 なので用紙上の実寸のまま)切り出される。例えば 100×70mm の窓は 100×70mm の図として貼り付く。ビューポートの中(モデル空間)に入った状態で `PETA` を実行した場合は、窓指定の間だけ自動でペーパー空間へ切り替わる
- **余白**: プロンプトで `M` を入力すると、切り出し範囲の外側へ付ける余白(mm)を指定できる(既定 0)
- 切り出し範囲の縁の精度は 0.2mm 程度である。縁ぎりぎりの線の切れ・余りが許容できない場合は余白を付ける
- **レイヤ**: `L` を入力すると、SVG がレイヤごとのグループになる(SVG 編集ソフトでレイヤ単位に扱う用途向け。描画の順番が変わるため重なりの見た目が崩れることがあり、EMF の描画順にも及ぶ。既定はオフ)
- **文字輪郭**: `T` を入力すると、TrueType を含む**すべての文字**が輪郭の図形として出力される(フォントが入っていない PC でも見た目が変わらない。文字編集はできなくなる。既定はオフ=フォント保持)

### 出力対象を選択オブジェクトだけに絞る(オブジェクト選択)

範囲(全体・窓)とは別に、その範囲の中で出力するオブジェクトを選択したものだけに絞れる。

1. オブジェクトを選択してから `PETA` を実行する。または `PETA` → `O` を入力してからオブジェクトを選択する(何も選ばず Enter すると絞り込みなしに戻る)
2. 続けて範囲を指定する。Enter(全体)か、2点指定の窓かは、絞り込みなしのときと同じ意味で効く

貼り付けサイズも絞り込みなしのときと同じ規則で決まる。レイアウトはページ設定の尺度のまま(通常 1:1 なので用紙上の実寸)、モデル空間は用紙合わせになる。

知っておくこと:

- 通常の選択図形は一時的な側DBへ複製してPDF印刷するため、**CTB/STB、色、線幅が反映される**。ビューポート選択は元図面の未確定トランザクション内で非選択のペーパー空間図形だけを隠して印刷する。どちらも元図面に変更を残さない。ファイル出力オンまたは診断時は内部生成PDFも保存する
- Defpoints等の非印刷レイヤにある非ビューポート図形を明示的に選んだ場合は、一時的な退避レイヤへその図形だけを移して出力する。通常ビューポートと同時に選んだ場合も、元レイヤや図面には変更を残さない
- 対象は現在の空間(モデル空間、またはカレントレイアウトのペーパー空間)直属のオブジェクトに限る。ペーパー空間のOnである通常ビューポートを選択すると、そのビューポートの尺度、視点、クリップ、VPフリーズ、画層overrideを通常のレイアウト印刷どおり反映する。`O`はビューポート内の非表示レイヤや非表示モデル図形を表示へ戻さない
- Xref、ペーパー空間の制御ビューポート、オフのビューポート、現在空間以外の図形など未対応の選択がある場合は既定で中止し、確認に同意した場合だけ対応図形を部分出力する
- 文字(マルチテキスト)の背景マスクは背景ごと再現される。背景に「図面の背景色を使用」を指定した文字(寸法値の背景によく使われる)は**白い塗りとして出力され、黒く塗りつぶされることはない**
- SHX文字はCADの印刷結果どおり輪郭として出る。文字として再編集したい場合は `PETADATA` で構造SVGを書き出す

### CAD構造を保ったSVGを書き出す（PETADATA）

`PETADATA` は選択オブジェクトをCADデータベースから直接読み、外部編集用SVGを保存する。
先選択してから実行するか、コマンド後にオブジェクトを選ぶ。
文字、レイヤ、元の色を保持し、貼付用EMF、内部PDF、クリップボードは生成しない。
CTB/STBは反映されない。
印刷と同じ見た目をOfficeへ貼る通常用途には `PETA`、InkscapeやIllustrator等でCAD構造を再編集する用途には `PETADATA` を使う。
尺度、余白、レイヤ、SHX代替、文字輪郭、グラデーションDPIを指定できる。

## 5. 貼り付け先ごとの注意

### Excel / PowerPoint

- Ctrl+V でそのまま貼り付く。サイズは実寸(誤差 0.1mm 程度)
- PowerPoint では、スライドからはみ出す大きさの図は、スライドに収まるよう縦横比を保って自動縮小される
- 図形への分解(第6章)は、この2アプリで行う

### Word(実寸の図として使う)

- Word では「形式を選択して貼り付け」→「図 (拡張メタファイル)」で貼ると実寸になる。そのまま Ctrl+V すると、既定では描画キャンバスの中へ入ることがある
- **描画キャンバスの中に入れない。** キャンバス内の図はキャンバスの大きさに合わせて縮小され、後からキャンバスを伸縮すると図も一緒に伸縮する。実寸を保つ用途に向かない
- 本文の幅より大きい図は、本文幅まで自動縮小される(例: A4 の既定設定では幅 150mm)。実寸が必要な場合は、貼り付けた後に図のサイズを数値で指定し直す。自動縮小でも縦横比は保たれている
- 図形への分解は Word では行わない(動作が不安定なため)。分解して編集したい図は Excel / PowerPoint に貼る

## 6. 図形に分解して編集する(Excel / PowerPoint)

貼り付けた図を右クリック→「グループ化」→「グループ解除」すると、図が個々の図形に変換され、線・塗り・文字を個別に編集できる。TrueType フォントの文字は文字のまま取り出され、フォントを保ったまま書き換えられる。

知っておくこと(Office 側の変換仕様):

- **分解した瞬間に、線の太さが画面の画素単位(0.75pt 刻み)へ丸められる。** 太さ 0.13〜0.35mm の線はすべて 0.75pt になり、0.05mm 以下の線は 0pt(最も細い線)になる。細い線を何段階か使い分けた図面でも、分解後は同じ太さに見える
- 分解せず画像のまま使う限り、線の太さは表示・印刷とも忠実に保たれる
- **Excel の分解では、日本語の一部の文字が「・」などに化けることがある**(Shift-JIS で2バイト目が特殊文字と重なる文字。例: ソ 能 表 施 図)。また、分解時に文字列の先頭へ「・」が挿入されることがある。いずれも Excel 側の変換の不具合であり、Windows 標準機能で作った図でも同様に化けることを確認済み。貼り付けたまま(画像のまま)なら化けない。PowerPoint の分解では起きない
- **図形の数が 1 万を超える図は、Excel と PowerPoint のどちらでもグループ解除(図形への変換)が失敗する。** 実測では、変換後の図形数 10,000 個までは成功し、10,001 個で失敗する。この閾値は Excel と PowerPoint で同じである。ファイルの大きさや線の込み具合ではなく、図形の個数だけで決まる(同じ大きさのファイルでも図形数が 1 万以下なら成功する)。失敗しても貼り付けそのものと実寸表示は正常であり、影響は図形へ分解できないことだけ

どうすればよいか:

- 線の太さの仕上がりが大事な図は、分解せず画像のまま貼る
- 分解して編集した図で太さの使い分けが必要な線は、Office 側で太さを指定し直す
- 文字の編集が要る図は PowerPoint で分解する。分解した図形は PowerPoint から Excel へコピーしても文字が保たれる(確認済み)
- 図形数が 1 万を超える図面(詳細の多い施工図等)は、分解せず画像のまま使う。分解編集が必要な場合は、PETA の範囲指定(2点窓)で編集したい範囲だけを切り出し、図形数を 1 万以下に抑えて貼る

## 7. 透過(透過性)を含む図面

オブジェクトやレイヤに透過性を設定している図面では、透過を仕上がりへ残すかどうかが AutoCAD の印刷設定で決まる。PETA はその設定に従う。

- 対象レイアウト(またはモデルタブ)のページ設定で「透過性を印刷」をオンにすると、PETA の出力にも透過が反映される。オフのまま実行すると、透過は消えてすべて不透明で出力される
- システム変数 `PLOTTRANSPARENCYOVERRIDE` でまとめて制御することもできる: 1=ページ設定に従う(既定)、2=常に透過を印刷、0=常に無視
- 透過を反映した場合の見え方は、出力形式で異なる
  - Ctrl+V で貼る図(EMF)は、白い紙の上で見た色に固定される(半透明のまま下が透ける表現を持たないため、白と混ぜた不透明色になる)。濃い色の背景へ置くと、白地で見た色のまま表示される。半透明の下に重なっていた線や図形も、不透明化した色に覆われて透けない
  - SVG ファイルは透過をそのまま保持する
- 透過の不透明化が起きた実行では、PETA が結果表示に続けて「透過図形検出。透過表現はSVGファイルを利用のこと」の注記をコマンドラインへ表示する
- 半透明の塗りつぶし(SOLID ハッチ×透過)は、AutoCAD の印刷段階で画像に変換される(第8章)

## 8. 変換の制約と対処

方式上どうしても起きる変化を「何が起きるか → どうすればよいか」で挙げる。

| 何が起きるか | どうすればよいか |
|---|---|
| SHX フォントの文字は線の集まりになり、文字としては編集できない | TrueTypeフォントを使うか、構造編集が必要なら `PETADATA` のSVGを使う |
| 斜体(傾斜角)を付けた TrueType 文字は直立で出力される(AutoCAD の印刷出力自体が傾斜を持たないため)。幅係数は保持される | 傾斜の再現が必要な注記には傾斜角を使わない |
| スプラインや線種付きの曲線は細かい折れ線になる | 見た目は保たれる。分解した後に曲線として編集し直す用途には向かない |
| 半透明の SOLID ハッチは画像になる(大きく拡大すると粗く見え、分解しても図形に戻らない) | 分解編集や高倍率の拡大が要る図では、ハッチの透過を外す(ハッチの境界や線は透過のままでも図形として保たれる) |
| 図面へ貼り込んだ OLE オブジェクト(Excel の表など)や画像は、画像のまま含まれ、ファイルが大きくなることがある | 表は図面へ貼り込まず Office 側で組むなど、元データの側で減らせる |
| 文字(マルチテキスト)の背景の「図面の背景色を使用」は、白い塗りとして出力される(貼り付け先=白い紙面を前提とするため) | 濃い色の背景へ置く資料では、背景マスクに明示的な色を指定する |

なお、Windows の表示スケール設定(125%・150% 等)は貼り付け寸法に影響しない(100/125/150% × 3アプリで同一寸法になることを確認済み)。

## 9. うまくいかないとき

- PETA はエラーの原因と対処をコマンドラインへ表示する。まずその表示を読む
- クリップボードへの登録に失敗した場合(他のアプリが使用中など)も、ファイルは出力済みである。表示されたアプリの操作を終えてから PETA を再実行するか、出力済みの `.emf` を Office へファイル挿入する
- 不具合を報告するときは、コマンドラインの表示全文と、出力ファイル一式（`.pdf` / `.svg` / `.emf`）を添える。切り分けに必要なら開発側が同じ操作を再現して調べる

## 10. 受け取った PDF ファイルを貼る(コマンドライン版)

AutoCAD が手元にない場合や、他社から図面を PDF でだけ受け取った場合は、コマンドライン版 `cadpeta.exe` で同じ品質の貼り付けができる。対象は CAD からプロットされたベクタ PDF である(スキャンした画像だけの PDF は、画像のまま貼られる)。

基本の使い方(コマンドプロンプトまたは PowerShell で):

```
cadpeta.exe 受領図面.pdf
```

これだけで図がコピーされた状態になり、Office で Ctrl+V すると PDF の用紙実寸で貼り付く。貼り付け用の EMF ファイルは一時フォルダ(`%TEMP%\cadpeta`)にも残り、パスが表示される。クリップボードへの登録に失敗した場合も、この EMF を Office へファイル挿入すれば同じ結果になる。

色を変えて貼る(カラーで受け取った図面をモノクロ資料へ載せる、など):

| コマンド | 動作 |
|---|---|
| `cadpeta.exe 図面.pdf --mono` | モノクロ化(紙面の白はそのまま、他の色は黒) |
| `cadpeta.exe 図面.pdf --gray` | グレースケール化(明るさを保った灰色) |
| `cadpeta.exe 図面.pdf --replace-color #FF0000 #000000` | 特定の色だけを置換(この例は赤→黒。複数回指定できる) |
| `cadpeta.exe 図面.pdf --text-outline` | すべての文字を輪郭の図形にする(フォントが入っていない PC でも見た目が変わらない。文字編集はできなくなる) |

ファイルとして残したい場合は出力名を指定する(この形はクリップボードへ登録しない。登録も併用するなら `--clipboard` を付ける):

```
cadpeta.exe 図面.pdf 図面.svg --emf 図面.emf
```

PDF・PNG のファイルも出力できる(Office 貼り付けの主役は引き続き EMF/SVG で、PDF は単票の受け渡し、PNG は見た目の確認用):

| コマンド | 動作 |
|---|---|
| `cadpeta.exe 図面.pdf 図面.svg --pdf 出力.pdf` | PDF を出力する(用紙実寸を保持。文字は輪郭の図形として埋め込むため、出力後の PDF では文字の検索・編集はできない) |
| `cadpeta.exe 図面.pdf 図面.svg --png 出力.png` | PNG(画像)を出力する(既定 150dpi) |
| `cadpeta.exe 図面.pdf 図面.svg --png 出力.png --png-dpi 300` | PNG の解像度を指定する |

色変換やクロップと組み合わせられる(例: `--mono --pdf 出力.pdf` でモノクロ化した PDF を渡す)。

処理の内容(何を何件変換したか)はコマンドラインに表示される。うまくいかないときの考え方は第9章と同じである。

## 11. グラデーションと貼り付け背景

選択オブジェクトの尺度指定画面では、`G`でグラデーション画像化の解像度をdpi指定できる
(既定150dpi)。LINEARを含む全9形状に対応する。グラデーションは見た目を保つ画像になるため、
Excel / PowerPointで図形へ変換しても、その部分はベクタ図形へ分解されない。

`B`ではEMFの半透明要素を不透明化するときの背景色を`#RRGGBB`で指定できる(既定白)。
色付きのスライドへ置く場合は貼付先と同じ色を指定する。CLIでは次のように指定する。

`cadpeta.exe 図面.pdf 図面.svg --emf 出力.emf --emf-bg "#102030"`

`--emf-bg`はEMF出力またはクリップボード登録と組み合わせる。SVG/PDF/PNGのアルファには影響しない。
# GUI版でPDFを貼り付ける

1. `cadpeta-gui.exe` を起動し、受領したPDFを画面へドロップします。
2. 色、背景、クロップ、文字アウトライン、レイヤの設定を選び、プレビューを確認します。
3. 「Officeに貼る」を押してWord、Excel、PowerPointで貼り付けるか、「ファイルに保存」で形式を選びます。
4. クリップボード登録に失敗した場合は、案内されたEMFをOfficeの「挿入 > 図」から選択します。

GUI版はCADを必要としませんが、.NET 10 Desktop Runtime x64が必要です。巨大PDFのキャンセルは安全な処理境界で反映されるため、解析中の
1ステージが完了するまで待つ場合があります。開発者向け段階診断はCLIの `--diag` を利用してください。

クロップ範囲は数値入力のほか、「範囲をドラッグ指定」を押して全面プレビュー上をドラッグして指定できます。
ドラッグ確定時は、指定した枠と出力範囲を一致させるため余白が0になります。Escキーまたは同じボタンで解除できます。

色置換では、プレビューから抽出した使用色一覧の色を押すと、選択中の行の「変換前」へ実際の図面色が入ります。
「スポイト」を押した場合は実色プレビューへ切り替わり、線や塗りをクリックして同じ操作ができます。白い余白や
アンチエイリアスだけをクリックしたときは色を変更しません。「変換後」は従来どおりセルをダブルクリックして選びます。
