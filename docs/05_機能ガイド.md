## 1. CadPeta とは

CadPeta は、AutoCAD（および互換CAD）の図面を Word / Excel / PowerPoint へ「拡大しても劣化しないベクタ図」として貼り付けるフリーソフトウェアです。
コマンド一つ（`PETA`）で印刷（プロット）と同じ仕上がりの図がコピーされた状態になり、Office 側で Ctrl+V するだけで用紙どおりの実寸で貼り付きます。
出力対象を図面上で選択したオブジェクトだけに絞ることも、受け取った PDF の図を CAD なしで貼ることもできます。

| できること | 使うもの | 章 |
|---|---|---|
| レイアウト／モデル空間を印刷の仕上がりどおり貼る（全体・窓切り出し） | `PETA` | 2, 3 |
| 出力対象を選択したオブジェクトだけに絞って貼る | `PETA` → オブジェクト(O) | 2, 3 |
| EMF / SVG / PDF / PNG の4形式で出力する | `PETA`・CLI・GUI | 4 |
| 出力する形式・出力先・ファイル名の形・PNG の解像度を設定する | `PETAOPT`・`-PETAOPT` | 3 |
| 用紙・尺度どおりの実寸で貼る（誤差は mm の小数第1位級） | 自動 | 5 |
| CAD構造を保った編集用SVGを書き出す | `PETADATA` | 2, 6 |
| 受け取った PDF のページを選び、色変換して図を貼る（CAD 不要） | `cadpeta.exe` | 7 |
| 受け取った PDF の図をプレビューで確かめながら貼る（CAD 不要） | `cadpeta-gui.exe` | 13 |
| Office 上で図形に分解し、線・塗り・文字を個別編集する | Excel / PowerPoint | 8 |

オブジェクト選択は範囲（全体・窓）の代替ではなく、範囲内の出力対象を絞るオプションです。
対象は現在空間直属の図形に限ります。
ペーパー空間のOnである通常ビューポートを選択すると、尺度、視点、クリップ、VPフリーズ、画層overrideを通常のレイアウト印刷どおり反映します。
オブジェクト(O)はビューポート内の非表示レイヤや非表示モデル図形を表示へ戻しません。
貼り付けサイズは絞り込みの有無によらず範囲プロットの規則（レイアウト＝ページ設定の尺度、モデル空間＝用紙合わせ）で決まります。

## 2. 貼付と構造SVGの使い分け

| | `PETA`（全体・窓、絞り込み可） | `PETADATA`（選択） |
|---|---|---|
| 仕上がり | **印刷と同じ**（CTB/STBの色・線幅を反映） | 図面の表示属性（CTB/STB非反映） |
| 成果物 | 貼付EMF（クリップボード）と、`PETAOPT` で選んだ形式のファイル（EMF・SVG・PDF・PNG） | 構造SVGのみ |
| 保持 | PDFのOCGレイヤ。その他は印刷結果へ平坦化 | 編集可能文字、レイヤ、元の色 |
| 向く用途 | Officeへの通常貼付 | Inkscape等でのCAD素材再編集 |

## 3. コマンド一つの動線（PETA）

`PETA` は一度に、ページ設定どおりの変換 → 設定した形式のファイル出力 → クリップボード登録（Ctrl+V で貼れる状態）まで行います。オプションの全体像:

| 入力 | 意味 |
|---|---|
| Enter | 全体を貼る（既定） |
| 2点指定 | 窓の範囲だけを切り出して貼る |
| オブジェクト(O) | 範囲内の出力対象を選択オブジェクトだけに絞る（先に選択してから `PETA` でも可） |
| 余白(M) | 切り出し範囲の外側へ付ける余白を mm で指定（既定 0） |
| レイヤ(L) | SVG をレイヤごとのグループにする（既定オフ。描画順が変わり得る） |
| 文字輪郭(T) | すべての文字を輪郭図形にする（既定オフ=フォント保持） |
| EMF背景(B) | EMF の半透明を不透明にするときの背景色を指定（既定は白。第12章） |

出力する形式（PDF・SVG・EMF・PNG。既定は EMF だけ）、出力先（既定は図面のフォルダの下の `CADPeta`）、ファイル名の形（差し込み `{drawing}`・`{tab}`・`{datetime}`・`{seq}`・`{comment}`）、PNG の解像度は、`PETAOPT`（ダイアログ）か `-PETAOPT`（コマンド ライン）で設定します。設定は利用者ごとに 1 つです。
ファイル名の形に `{comment}` を入れると、`PETA` のたびにコメントを入力するダイアログが開き、入力の間に図の変換が進みます。同じ名前のファイルがあるときは、名前の後に (1)、(2) のような番号を付けます。
AutoCAD と ARES 2023 以降では、リボンの「アドイン」タブの CADPeta のパネルの「PETA」のボタンで `PETA` を、「設定」のボタンで `PETAOPT` を実行できます（ARES 2020 にはリボンのパネルを置きません）。

## 4. 4つの出力形式の使い分け

| 形式 | 特徴 | 向く用途 |
|---|---|---|
| EMF | Ctrl+V で貼れる主形式。実寸保証。Excel / PowerPoint で図形に分解できる | Office への貼り付け全般 |
| SVG | 透過をそのまま保持。ブラウザで開ける。Office 2016 以降は直接挿入も可。レイヤ別グループ化（Inkscape 等でレイヤパネルに出る）を選べる | 長期保存・再利用・SVG 編集ソフトでの加工 |
| PDF | 用紙実寸を保持した単票。破線・透過・クリップを PDF ネイティブで無劣化収録（文字は輪郭化のため検索・編集は不可） | 図面 PDF の受け渡し・互換確認 |
| PNG | 画像（既定 300dpi、24～600dpi で指定可） | 見た目の確認・ベクタを受け取れない環境向け |

クリップボードに載るのは EMF です。登録時に読み戻し検証を行い、他アプリの使用中などで失敗した場合もファイルは出力済みのため、ファイル挿入で代替できます。

## 5. 実寸で貼れる（精度の実測値）

- 貼り付け直後のサイズは用紙・尺度どおりの実寸になります。実測誤差は実物図面の切り出しで **±0.11mm 以内（0.16% 以下）**、A3 レイアウト全体で 0.1mm 程度です
- 互換CAD（ARES・IJCAD・BricsCAD）でも +0.32mm 以内で、EMF が持つ実寸情報は AutoCAD と同値です
- レイアウトの印刷尺度は、その尺度どおりに貼り付きます
- 窓切り出しの縁の精度は 0.2mm 程度です（縁ぎりぎりの線が惜しい場合は余白を付けてください）
- Windows の表示スケール設定（100 / 125 / 150%）は貼り付け寸法に影響しません
- Word だけは本文幅を超える図を自動縮小します（縦横比は保持。貼り付け後のサイズ再設定で実寸に戻せます。04 §5）

## 6. 文字をどう扱えるか

- **TrueType の文字は文字のまま**出力されます。Office で図形に分解した後も、フォントを保ったまま書き換えられます
- **SHX フォント（romans・txt、extfont2 等のビッグフォント含む）の文字は、既定で図面の字形どおりの輪郭**として出力されます（AutoCAD 実機の描画との機械比較で字形一致を確認済み）。線になるため文字としては編集できません
- CADの文字構造を保持して編集したい場合は **`PETADATA`** を使います。SHX代替も `PETADATA` で指定できます
- **文字輪郭(T)**（CLI は `--text-outline`）はすべての文字を輪郭化します。フォントが入っていない PC でも見た目が変わりません（文字編集はできなくなります）

## 7. 受け取った PDF の図を貼る（CLI）

CAD が手元にない場合や PDF でだけ図面を受け取った場合は、コマンドライン版 `cadpeta.exe` で同じ品質の貼り付けができます。対象は CAD からプロットされたベクタ PDF です。

```
cadpeta.exe 受領図面.pdf
```

これだけで図がコピーされた状態になり、Ctrl+V で PDF の用紙実寸のまま貼り付きます（出力を指定しない場合はクリップボード登録が既定動作です。EMF は一時フォルダにも残ります）。

色を変えて貼れます: `--mono`（モノクロ化。紙面の白はそのまま、他の色は黒）、`--gray`（明るさを保った灰色）、`--replace-color #RRGGBB #RRGGBB`（特定色の置換。複数指定可。`--tolerance N` を続けると、R・G・B のそれぞれの差が N 以内の近い色もまとめて置換します）。
カラー図面をモノクロ資料へ載せる、といった作業が CAD なしで完結します。

複数ページの PDF は `--pages 3` や `--pages 1-3,5` で変換するページを選びます（既定は 1 ページ目）。
2 ページ以上を選ぶと、出力のファイル名にページの番号（`-p2` など）を付けます。

全オプション: ページ（`--pages`）、出力ファイル指定（`出力.svg`・`--emf`・`--pdf`・`--png`・`--png-dpi`）、範囲（`--crop x0 y0 x1 y1`・`--margin`）、色（`--mono`・`--gray`・`--replace-color`・`--tolerance`）、構造（`--layer-groups`・`--text-outline`）、その他（`--clipboard`・`--keep-bg`=背景除去の無効化・`--diag`=各段ダンプ）。コマンド例は 04 §10 にあります。

## 8. Office 側でできること・起きること

- **図形への分解**（右クリック→グループ解除）は Excel / PowerPoint で行えます。分解後は線・塗り・文字を個別に編集でき、TrueType の文字はフォントを保って書き換えられます
- 分解できるのは**図形数 10,000 個まで**です（10,001 個で失敗。ファイルの大きさは無関係で、4.2MB・1万図形は成功し、418KB・1万1図形は失敗する対照実験で確認済み）。失敗しても貼り付けと実寸表示は正常で、影響は分解できないことだけです。超える図面は窓切り出しで範囲を絞れば分解できます
- 分解した瞬間に、線の太さは画面の画素単位（0.75pt 刻み）へ丸められます（0.13〜0.35mm の線は一律 0.75pt、0.05mm 以下は 0pt）。**分解せず画像のまま使う限り、線の太さは表示・印刷とも忠実**です
- Excel の分解では一部の日本語（ソ・能・表・施・図 等）が「・」に化けることがあります（Excel 側の変換の不具合。PowerPoint の分解では起きません）
- PowerPoint はスライドからはみ出す図を、縦横比を保って自動縮小します
- Word は分解編集に向かないため、実寸の図として使います（本文幅を超えると自動縮小。例: A4 既定設定で幅 150mm。04 §5）

## 9. 対応環境

- **AutoCAD 2024〜2027**（実行基盤: 2024 以前 = .NET Framework 4.8、2025・2026 = .NET 8、2027 = .NET 10 の3系。2024・2026・2027 は実機確認済みで、2027 の出力は 2026 とバイト一致）
- **互換CAD**: ARES 2020／2023／2024／2027、IJCAD 2026、BricsCAD V26に対応します。ARES 2020／2023 は .NET Framework 4.8 版です（Windows 10／11 に標準で入っています）。この版（1.1.0）は ARES 2020／2023／2024／2027 の実機で確かめました。IJCAD と BricsCAD は実機で確かめていません
- **Office**: Word / Excel / PowerPoint（Windows デスクトップ版）。**OS**: Windows 10 / 11
- **CLI**（`cadpeta.exe`）と **GUI**（`cadpeta-gui.exe`）は CAD のインストール不要です（GUI は .NET 10 Desktop Runtime x64 が必要です）
- プラグインは同梱の `install.bat` でインストールし、CAD の起動時に自動で読み込まれます（手順は 04 §2）

## 10. 方式に内在する制約

いずれも発生件数と対象が処理記録に残ります。対処は 04 §8 が詳しいです。

- Ctrl+V で貼る図（EMF）の透過は、白い紙の上で見た色に固定されます（SVG ファイルは透過をそのまま保持します）
- `PETA` はすべての入口でハッチ等の意味単位を PDF の段階で平坦化します。意味単位での後編集には `PETADATA` を使ってください
- SHX 輪郭・文字輪郭(T) の文字は編集できません（第6章）
- 斜体（傾斜角）を付けた TrueType 文字は直立で出力されます（プロット出力自体が傾斜を持たないため）
- 半透明の SOLID ハッチは印刷段階で画像になります（高倍率の拡大で粗く見え、分解しても図形に戻りません）
- スプラインや線種付きの曲線は細かい折れ線になります（見た目は保たれます）

## 11. フリーソフトウェアとしての設計

- 本体は無償配布で、AGPL 等の強いコピーレフトや有償 SDK に依存しません
- インストールに管理者権限とドライバ署名を要求しません（仮想プリンタ方式を採りません）
- 不具合は、開発側のデバッグコマンド `PETADIAG` が生成する処理記録（`.svg.diag.json`）と各段ダンプで、「取得・変換・出力のどこの問題か」まで追えます（開発者向け。仕様は 03 §9）

## 12. グラデーションを含む図面

- `PETADATA` の尺度のプロンプトで `G` を選ぶと、グラデーションの画像化解像度を指定できます（既定150dpi）
- LINEAR、CYLINDER、SPHERICALなどAutoCAD互換の全9形状を扱います
- 見た目は保持されますが、Officeで図形へ変換してもグラデーション部分は画像のままです
- EMFを色付き背景へ置くときは、`PETA` の `B` か CLI の `--emf-bg` へ貼付先の `#RRGGBB` を指定してください
- SVG、PDF、PNGではアルファを保持できます。背景色指定はEMFの不透明化だけに作用します

## 13. 受け取った PDF の図を画面で確かめて貼る（GUI）

GUI 版 `cadpeta-gui.exe` は、CLI と同じ変換（ページの選択、背景除去、範囲の切り出し、色置換、モノクロ化・グレースケール化、文字の輪郭化、レイヤ別グループ化、EMF の背景色、PNG の解像度）を、プレビューを見ながら設定できます。
変換した図はクリップボードにコピーして Office へ貼るか、EMF / SVG / PDF / PNG のうちチェックした形式で保存します。
プレビューは PNG ですが、クリップボードにコピーする図はベクタの EMF です。

- 範囲の切り出しは、mm の数値の入力か、ページ全体のプレビューの上のドラッグで指定します
- 色置換は、図面の使用色の一覧（すべての色を使用の多い順に表示）か、スポイトで置換元を選びます。スポイトは、クリックした位置で一番上に描かれた図形の元の色を取るので、近い色が多い図面でも別の色と取り違えません
- 色置換の許容差（R・G・B のそれぞれの差の上限）を行ごとに指定でき、行ごとに一致した色の数と件数を表示します
- 画面の配色は Windows のアプリの配色（暗い・明るい）に合わせます

操作の手順は 04 §12 にあります。段階ごとの診断のダンプは、開発者向けに CLI だけが持っています。
