## 1. CadPeta とは

CadPeta は、AutoCAD（および互換CAD）の図面を Word / Excel / PowerPoint へ「拡大しても
劣化しないベクタ図」として貼り付けるフリーソフトウェアである。コマンド一つ（`PETA`）で
印刷（プロット）と同じ仕上がりの図がコピーされた状態になり、Office 側で Ctrl+V するだけで
用紙どおりの実寸で貼り付く。出力対象を図面上で選択したオブジェクトだけに絞ることも、
受け取った PDF から CAD なしで貼ることもできる。

| できること | 使うもの | 章 |
|---|---|---|
| レイアウト／モデル空間を印刷の仕上がりどおり貼る（全体・窓切り出し） | `PETA` | 2, 3 |
| 出力対象を選択したオブジェクトだけに絞って貼る | `PETA` → オブジェクト(O) | 2, 3 |
| EMF / SVG / PDF / PNG の4形式で出力する | `PETA`・CLI | 4 |
| 用紙・尺度どおりの実寸で貼る（誤差は mm の小数第1位級） | 自動 | 5 |
| CAD構造を保った編集用SVGを書き出す | `PETADATA` | 2, 6 |
| 受け取った PDF を色変換して貼る（CAD 不要） | `cadpeta.exe` | 7 |
| Office 上で図形に分解し、線・塗り・文字を個別編集する | Excel / PowerPoint | 8 |

オブジェクト選択は範囲（全体・窓）の代替ではなく、範囲内の出力対象を絞るオプションである。
対象は現在空間直属の図形に限る。
ペーパー空間のOnである通常ビューポートを選択すると、尺度、視点、クリップ、VPフリーズ、画層overrideを通常のレイアウト印刷どおり反映する。
オブジェクト(O)はビューポート内の非表示レイヤや非表示モデル図形を表示へ戻さない。
貼り付けサイズは絞り込みの有無に依らず範囲プロットの規則（レイアウト＝ページ設定の尺度、モデル空間＝用紙合わせ）で決まる。

## 2. 貼付と構造SVGの使い分け

| | PETA（全体・窓、絞り込み可） | PETADATA（選択） |
|---|---|---|
| 仕上がり | **印刷と同じ**（CTB/STBの色・線幅を反映） | 図面の表示属性（CTB/STB非反映） |
| 成果物 | 貼付EMF、SVG、内部印刷PDF | 構造SVGのみ |
| 保持 | PDFのOCGレイヤ。その他は印刷結果へ平坦化 | 編集可能文字、レイヤ、元の色 |
| 向く用途 | Officeへの通常貼付 | Inkscape等でのCAD素材再編集 |

## 3. コマンド一つの動線（PETA）

`PETA` は一度に、ページ設定どおりの変換 → 必要に応じた図面フォルダへのファイル出力 →
クリップボード登録（Ctrl+V で貼れる状態）まで行う。オプションの全体像:

| 入力 | 意味 |
|---|---|
| Enter | 全体を貼る（既定） |
| 2点指定 | 窓の範囲だけを切り出して貼る |
| オブジェクト(O) | 範囲内の出力対象を選択オブジェクトだけに絞る（先に選択してから `PETA` でも可） |
| 余白(M) | 切り出し範囲の外側へ付ける余白を mm で指定（既定 0） |
| レイヤ(L) | SVG をレイヤごとのグループにする（既定オフ。描画順が変わり得る） |
| 文字輪郭(T) | すべての文字を輪郭図形にする（既定オフ=フォント保持） |
| ファイル出力(F) | 図面フォルダへのファイル保存を切り替える（既定オン） |

通常の出力ファイルは EMF・SVG・PDFである。選択も内部PDFを経由し、ファイル出力オンまたは診断時に保存する。

## 4. 4つの出力形式の使い分け

| 形式 | 特徴 | 向く用途 |
|---|---|---|
| EMF | Ctrl+V で貼れる主形式。実寸保証。Excel / PowerPoint で図形に分解できる | Office への貼り付け全般 |
| SVG | 透過をそのまま保持。ブラウザで開ける。Office 2016 以降は直接挿入も可。レイヤ別グループ化（Inkscape 等でレイヤパネルに出る）を選べる | 長期保存・再利用・SVG 編集ソフトでの加工 |
| PDF | 用紙実寸を保持した単票。破線・透過・クリップを PDF ネイティブで無劣化収録（文字は輪郭化のため検索・編集は不可） | 図面 PDF の受け渡し・互換確認 |
| PNG | 画像（既定 150dpi、解像度指定可） | 見た目の確認・ベクタを受け取れない環境向け |

クリップボードに載るのは EMF である。登録時に読み戻し検証を行い、他アプリの使用中などで
失敗した場合もファイルは出力済みのため、ファイル挿入で代替できる。

## 5. 実寸で貼れる（精度の実測値）

- 貼り付け直後のサイズは用紙・尺度どおりの実寸になる。実測誤差は実物図面の切り出しで
  **±0.11mm 以内（0.16% 以下）**、A3 レイアウト全体で 0.1mm 程度
- 互換CAD（ARES・IJCAD・BricsCAD）でも +0.32mm 以内で、EMF が持つ実寸情報は AutoCAD と
  同値である
- レイアウトの印刷尺度は、その尺度どおりに貼り付く
- 窓切り出しの縁の精度は 0.2mm 程度（縁ぎりぎりの線が惜しい場合は余白を付ける）
- Windows の表示スケール設定（100 / 125 / 150%）は貼り付け寸法に影響しない
- Word だけは本文幅を超える図を自動縮小する（縦横比は保持。貼り付け後のサイズ再設定で実寸に
  戻せる。04 §5）

## 6. 文字をどう扱えるか

- **TrueType の文字は文字のまま**出力される。Office で図形に分解した後も、フォントを保った
  まま書き換えられる
- **SHX フォント（romans・txt、extfont2 等のビッグフォント含む）の文字は、既定で図面の
  字形どおりの輪郭**として出力される（AutoCAD 実機の描画との機械比較で字形一致を確認済み）。
  線になるため文字としては編集できない
- CADの文字構造を保持して編集したい場合は **PETADATA** を使う。SHX代替もPETADATA側で指定できる
- **文字輪郭(T)**（CLI は `--text-outline`）はすべての文字を輪郭化する。フォントが入って
  いない PC でも見た目が変わらない（文字編集はできなくなる）

## 7. 受け取った PDF を貼る（CLI）

CAD が手元にない場合や PDF でだけ図面を受け取った場合は、コマンドライン版 `cadpeta.exe` で
同じ品質の貼り付けができる。対象は CAD からプロットされたベクタ PDF である。

```
cadpeta.exe 受領図面.pdf
```

これだけで図がコピーされた状態になり、Ctrl+V で PDF の用紙実寸のまま貼り付く（出力を
指定しない場合はクリップボード登録が既定動作。EMF は一時フォルダにも残る）。

色を変えて貼れる: `--mono`（モノクロ化。紙面の白はそのまま、他の色は黒）、`--gray`
（明るさを保った灰色）、`--replace-color #RRGGBB #RRGGBB`（特定色の置換。複数指定可）。
カラー図面をモノクロ資料へ載せる、といった動線が CAD なしで完結する。

全オプション: 出力ファイル指定（`出力.svg`・`--emf`・`--pdf`・`--png`・`--png-dpi`）、
範囲（`--crop x0 y0 x1 y1`・`--margin`）、色（`--mono`・`--gray`・`--replace-color`）、
構造（`--layer-groups`・`--text-outline`）、その他（`--clipboard`・`--keep-bg`=背景除去の
無効化・`--diag`=各段ダンプ）。コマンド例は 04 §10 にある。

## 8. Office 側でできること・起きること

- **図形への分解**（右クリック→グループ解除）は Excel / PowerPoint で行える。分解後は線・
  塗り・文字を個別に編集でき、TrueType の文字はフォントを保って書き換えられる
- 分解できるのは**図形数 10,000 個まで**である（10,001 個で失敗。ファイルの大きさは無関係:
  4.2MB・1万図形は成功し、418KB・1万1図形は失敗する対照実験で確認済み）。失敗しても
  貼り付けと実寸表示は正常で、影響は分解できないことだけ。超える図面は窓切り出しで範囲を
  絞れば分解できる
- 分解した瞬間に、線の太さは画面の画素単位（0.75pt 刻み）へ丸められる（0.13〜0.35mm の線は
  一律 0.75pt、0.05mm 以下は 0pt）。**分解せず画像のまま使う限り、線の太さは表示・印刷とも
  忠実**である
- Excel の分解では一部の日本語（ソ・能・表・施・図 等）が「・」に化けることがある（Excel 側の
  変換の不具合。PowerPoint の分解では起きない）
- PowerPoint はスライドからはみ出す図を、縦横比を保って自動縮小する
- Word は分解編集に向かないため実寸の図として使う（本文幅を超えると自動縮小。例: A4 既定
  設定で幅 150mm。04 §5）

## 9. 対応環境

- **AutoCAD 2024〜2027**（実行基盤: 2024 以前 = .NET Framework 4.8、2025・2026 = .NET 8、
  2027 = .NET 10 の3系。2024・2026・2027 は実機確認済みで、2027 の出力は 2026 と
  バイト一致）
- **互換CAD**: ARES 2020／2023／2024／2027、IJCAD 2026、BricsCAD V26に対応。ARES 2020／2023 は .NET Framework 4.8 版（Windows 10／11 に標準で入っている）。側DB複製の印刷と範囲内絞り込みの実機E2Eは ARES 2024／2027、IJCAD 2026、BricsCAD V26 で確認済み。ARES 2020／2023 の実機状況は `docs/validation/compatible-cad.md` に記録する
- **Office**: Word / Excel / PowerPoint（Windows デスクトップ版）。**OS**: Windows 10 / 11
- **CLI**（`cadpeta.exe`）は CAD のインストール不要
- プラグインの読み込みは `NETLOAD`（手順は 04 §2）

## 10. 方式に内在する制約

いずれも発生件数と対象が処理記録に残る。対処は 04 §8 が詳しい。

- Ctrl+V で貼る図（EMF）の透過は、白い紙の上で見た色に固定される（SVG ファイルは透過を
  そのまま保持する）
- PETAは全入口でハッチ等の意味単位をPDF段階で平坦化する。意味単位での後編集にはPETADATAを使う
- SHX 輪郭・文字輪郭(T) の文字は編集できない（第6章）
- 斜体（傾斜角）を付けた TrueType 文字は直立で出力される（プロット出力自体が傾斜を
  持たないため）
- 半透明の SOLID ハッチは印刷段階で画像になる（高倍率の拡大で粗く見え、分解しても図形に
  戻らない）
- スプラインや線種付きの曲線は細かい折れ線になる（見た目は保たれる）

## 11. フリーソフトウェアとしての設計

- 本体は無償配布であり、AGPL 等の強いコピーレフトや有償 SDK に依存しない
- インストールに管理者権限とドライバ署名を要求しない（仮想プリンタ方式を採らない）
- 不具合は、開発側のデバッグコマンド `PETADIAG` が生成する処理記録（`.svg.diag.json`）と各段ダンプで
  「取得・変換・出力のどこの問題か」まで追える（開発者向け。仕様は 03 §9）

## 12. グラデーションを含む図面

- PETADATAの選択動線で`G`を選ぶと、グラデーションの画像化解像度を指定できる（既定150dpi）。
- LINEAR、CYLINDER、SPHERICALなどAutoCAD互換の全9形状を扱う。
- 見た目は保持されるが、Officeで図形へ変換してもグラデーション部分は画像のままである。
- EMFを色付き背景へ置くときは、PETAの`B`またはCLIの`--emf-bg`へ貼付先の`#RRGGBB`を指定する。
- SVG、PDF、PNGではアルファを保持できる。背景色指定はEMFの不透明化だけに作用する。
# PDF GUI版

GUI版は、CLIの通常利用機能である背景除去、クロップ、色置換、モノクロ・グレースケール化、文字アウトライン、
レイヤ別グループ化、EMF背景色、PNG DPI、Clipboard/EMF/SVG/PDF/PNG出力を共有Application層から提供します。
プレビューはPNG、Office貼り付けはベクタのEMFです。段階SVG診断ダンプだけは開発者向けCLI専用です。

クロップはミリメートル値の直接入力に加え、全面プレビュー上のドラッグ指定に対応します。色置換は内部表現（IR: Intermediate
Representation）に残る使用色を一覧表示し、一覧またはスポイトから置換元を指定できます。スポイト表示では色変換を一時的に外し、
アンチエイリアスされた画素をIRの実色へ近似するため、画面上の補間色を誤って置換規則へ登録しません。保存・Office貼り付けには
一時表示の設定を流用せず、画面で指定されたクロップと色変換を常に適用します。
