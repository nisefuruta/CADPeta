# CADPeta 総合テストチャート

`gen_testchart.lsp` は、設計書§3.2「エンティティからIRへの対応」の各行を網羅する
テストチャート図面を機械生成する AutoLISP スクリプトである。
生成した図面をベクタPDFへプロットし、PDF解析・PETA印刷・PETADATA書き出し・出力形式の恒久回帰入力とする。

## 使い方

1. mm系テンプレート（`acadiso.dwt` 等）で新規図面を開く
2. `APPLOAD` で `gen_testchart.lsp` をロードする
3. コマンド `TESTCHART` を実行する
4. 生成された図面を DWG ファイルとして保存する（コーパスの基準とする）
5. 下記の設定でベクタPDFへプロットする

## 図面の構成

- 外枠 400×280mm、左下原点。**外枠寸法と左下の100mm目盛が実寸再現（FR-6）の測定基準**
- 縦軸（19行）: 線分／ポリライン（円弧・全体幅）／円／円弧／楕円／楕円弧／スプライン／
  文字 TrueType（英・日・変形〔幅0.8/斜体15°、PDFでジオメトリ化される条件の実測用〕）／
  文字 SHX（romans・BigFont）／ハッチ（SOLID・ANSI31・GRAVEL）／
  ワイプアウト／ブロック参照（ByBlock・回転30°尺度1.2）／入れ子ブロック／寸法
- 横軸（6列）: ACI 1（赤）／TrueColor 30,144,255／ByLayer（緑レイヤ）／透過50%／
  線種 DASHED／線幅 0.53mm
- 適用外の組み合わせ（文字×線種等）はセルに「-」を表示する
- ワイプアウト行は、下地図形 → ワイプアウト → 上載せ線の描画順とし、
  マスクが描画順に従うことを確認できる配置にしてある
- ブロック TC_BLK は ByBlock 色の図形に加えて**固定 ACI 1 の線**を含む。
  挿入色に引きずられず固定色が保持されることを同時に検証する

## プロット設定（記録すること）

検証の再現性のため、プロット時に以下を必ず記録する（todo 準備節の項目）。

| 項目 | 推奨値 | 記録欄 |
|---|---|---|
| PDFドライバ | AutoCAD PDF (High Quality Print).pc3 | |
| 用紙 | ISO A3 (420×297mm) | |
| 尺度 | 1:1 | |
| プロットスタイル | なし（オブジェクト色のまま） | |
| 透過性のプロット | **オン**（列4の検証に必須） | |
| プロット領域 | 窓（外枠に一致させる） | |
| `EPDFSHX` | 0 と 1 の両方で1枚ずつ | |

`EPDFSHX=1` は SHX 文字の元テキストを PDF 注釈として埋め込む（PETA/PDF入力のテキスト復元検証用）。
普段の運用が 0 の環境では、検証後に 0 へ戻すこと。
**注意: accoreconsole には EPDFSHX が存在しないため、注釈付きPDFは対話セッションのプロットでしか作れない**（検証記録_ハッチソリッド化.md 追記参照）。

## コーパスの現状（2026-07-06）

| ファイル | 生成経路 | 備考 |
|---|---|---|
| `TESTCHART.dwg` + `PDF出力20260706-01.pdf` | 初版チャート／対話プロット | AR-CONC 行がソリッド化した記録標本として保持 |
| `TESTCHART2.dwg` + `TESTCHART2_console_1to1.pdf` | 改訂チャート（GRAVEL・TT変形行入り）／accoreconsole・HQ・A3・1:1 | 自動検証用 |
| `TESTCHART2-off.pdf`（EPDFSHX=0）/ `TESTCHART2-on.pdf`（EPDFSHX=1） | 対話セッション・HQ・A3フルブリード・1:1・透過オン | **コーパスの正**。構造の実測結果は `../検証記録_プロットPDF構造.md`、抽出比較は `../検証記録_抽出比較.md` |
| `TESTCHART2_layout.dwg` + `gen_layout_testchart.scr` | TESTCHART2.dwg へレイアウト PETA_A3（A3フルブリード・ビューポート1:1・monochrome.ctb）を焼き込んで生成（2026-07-07） | レイアウト、プロットスタイル、実寸の回帰図面。scr の再実行でDWGと基準PDFを再生成できる |
| `STB_RECT.dwg` + `gen_stb_testchart.scr` | acadISO -Named Plot Styles.dwt（PSTYLEMODE=0）へ 20×10mm 矩形を entmake して生成（2026-07-15） | STB（名前の付いた印刷スタイル）図面の選択印刷回帰用。scr の再実行で再生成できる |

既知の生成時アーティファクト（現行コーパスに含まれる。抽出検証には支障なし）:

- 一部の「-」プレースホルダが赤・透過50%等の明示属性を持つ（entmake の属性焼き込み。
  `gen_testchart.lsp` は 2026-07-06 修正済み。現コーパスは修正前生成物で、
  「明示色+明示透過付き文字」の検証ケースとして有用なため再生成しない）
- 楕円弧行（行6）は弧が下向きに生成され、行7の帯に食い込む（次回チャート改訂時に修正）

プロットスタイル反映済み仕上がりの検証は、同じ図面を
monochrome.ctb 等で再プロットすれば入力を追加できる。

## 環境依存の注意

- `DASHED` 線種は `acadiso.lin`（なければ `acad.lin`）から自動ロードする。
  どちらも見つからない場合、列5は実線のまま生成される
- 文字スタイルは `arial.ttf` / `msgothic.ttc` / `romans.shx` / `extfont.shx` を使う。
  欠けているフォントは AutoCAD の代替フォントで表示される（その場合は記録すること）
- `GRAVEL` の粗密はスクリプト冒頭の `tc:hatch-scale-grv` で調整できる。
  当初の AR-CONC は実寸（インチ）基準パターンのため、このセル寸法では
  密度上限（HPMAXLINES）超過によるソリッド化を避けられず、GRAVEL に置き換えた
- `WIPEOUTFRAME=2`（枠は画面表示のみ、プロットしない）を設定する。
  旧バージョンで値2が使えない場合は現状値のまま動作する
