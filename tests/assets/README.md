# 検証入力コーパス

CADPeta の出力互換性を継続検証する、再現可能な入力と正解標本を置く。
開発段階別ではなく、検証対象別に管理する。

| ディレクトリ | 用途 |
|---|---|
| `testcharts/` | PDF解析、PETA印刷/PETADATA書き出し、透過、クロップ、実寸の総合チャート |
| `testcharts/gradient/` | AutoCAD純正プロットによる全9グラデーション形状の正解PDF、生成器、固定格子ゴールデン |
| `emf-samples/` | OfficeでのEMF分解・透過・実寸挙動を比較する最小標本 |

チャートの生成条件、既知のアーティファクト、再生成方法は各ディレクトリのREADMEを基準とする。
生成途中のログ、レンダ画像、差分タイル、`bin`/`obj` は追跡しない。
